ALVR 20 的当前绑定
===

要控制手势状态，您可以切换 `头显 -> 控制器 -> 手势 -> 仅触摸`
启用状态表示手势不会被触发，禁用状态表示所有手势都被激活。

手势
---

| 动作           | 手部追踪捏合                      |
| -------------- | --------------------------------- |
| 扳机           | 拇指和食指捏合                    |
| 摇杆点击       | 拇指卷曲到手掌                    |
| 抓握           | 中指、无名指和小指卷曲            |
| Y/B            | 拇指和中指捏合                    |
| X/A            | 拇指和无名指捏合                  |
| 菜单按钮       | 左手拇指和小指捏合                |

摇杆
---

通过弯曲所有 4 根手指并用拇指触摸手背来激活
